# CSV unit converter
CSV unit converter > simple unit conversion from diagnostic tool

simple program for converting measured values ​​in CSV file.

converts:
1.	temperature
2.	distance
3.	voltage
4.	current
5.	pressure
6.	time
7.	air mass
8.	logical states (on/off, open/close,... to 1/0)
